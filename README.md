## 🔗 INTEGRATION WITH BACKEND

The frontend forms (enrol, login, verify) have JavaScript hooks ready for backend integration:

### Enrol Form
- Submits to: `POST /backend/api/enrol.php`
- Data: first_name, last_name, email, phone, id_number, programme_id

### Login Form
- Submits to: `POST /backend/api/login.php`
- Data: email, password

### Verify Certificate
- Submits to: `GET /backend/api/verify.php`
- Data: certificate_number
